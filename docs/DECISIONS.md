# 夜讀（Night Reading）— 已拍板決策與現況

> 單一真理來源。每拍一個板就更新這份。研究流程與數據見 `research/`，紅線測試見 `research/nightread_guard.py`。

## 定位

漫畫夜讀模式＝**頁面本身**變暗（不是 UI 黑）。業界所有 reader 只做 UI 黑或硬反相；沒有人動過頁面內容——可能首創。
數學結論（實驗確立、別再挑戰）：漫畫的紙白參與構圖（臉的亮部、留白都用紙白畫）⇒「白→暗」的全域函式無解；
只有**分區重繪**（氣泡深底亮字、背景填黑、前景白描邊）拿得到夜讀效果——這是 Yakuyomi 的護城河，濾鏡永遠做不到。

## 現況（2026-09-14）

- 管線：偵測（DBNet，來自 engine parity）→ 頁型判別 → 白元件分類 → 氣泡遮罩 → 貼紙計畫 → 合成（曲線／留白／貼紙／氣泡／偽泡／人頭一致化）。細節見 `research/nightread.py` 檔頭。
- 守護框：最好的配置仍 **37–55 框違規**。剩餘違規全是「臉頰／手／白衣與紙白連續、無窄頸、無墨團」——深度、面積比、實心度（原始／填洞）、貼厚墨、貼框／貼泡、肥留白全試過，**沒有任何局部幾何或灰階特徵可分**。
- **結論：紅線在無語意（人物分割）下不可達。** 別再靠加門檻／旗標追這條線。
- 已知待修（小）：偽泡的厚墨灰暈把粗體字筆畫當墨團 → 字旁挖出灰洞（修法：算灰暈前扣掉文字筆畫遮罩）。
- 待另案：demo01（出血特寫 + 字壓臉）＝極端頁，等分割模型。

## 下一步（人物分割）

調研結論（2026-09-08）：沒有現成模型在黑白漫畫上驗證過人物遮罩；零樣本分割在漫畫人物 Mask AP 僅 0.27。
1. 半天探針：SkyTNT `isnetis.onnx`（Apache-2.0）+ anonimkaq4 YOLO11-seg（唯一黑白漫畫訓練的像素遮罩）對 11 頁出遮罩，當禁填區餵守護框看違規降多少。
2. 臉框保險：deepghs/manga109_yolo（黑白漫畫訓練、ONNX 現成、n 版 3M）——臉框內永遠禁填。
3. 若探針證明語意路可行：用 MS92/MangaSegmentation（CVPR 2025、允許商用需標註）自訓小 seg 模型（YOLO11n/s-seg 沾 AGPL、或 RTMDet-Ins Apache），ncnn 上機。
